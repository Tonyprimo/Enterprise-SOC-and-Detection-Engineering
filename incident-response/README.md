# Incident Response

This folder documents the end-to-end incident response exercise performed during Sprint 12 of the Enterprise SOC Lab.

The exercise simulated common Windows administrative activity that could indicate malicious behavior if observed in a production environment. Splunk Enterprise was used to investigate the activity, correlate events across multiple data sources, and document the complete incident lifecycle.

## Objectives

- Detect suspicious endpoint activity
- Investigate Windows and Sysmon telemetry
- Correlate events using Splunk
- Build an incident timeline
- Collect and document evidence
- Perform containment and remediation
- Validate successful cleanup
- Produce executive and technical reporting

## Simulated Activity

- PowerShell execution
- Command Prompt execution
- Certutil execution
- Active Directory account creation
- Local administrator group modification
- Security event investigation

## Data Sources

- Windows Security Logs
- Sysmon
- PowerShell Operational Logs
- Splunk Enterprise

## Deliverables

- Incident Report
- Timeline
- Evidence Log
- Containment & Remediation
- Executive Summary
- Lessons Learned
